TryHackMe: Phishing Investigation

This project focused on investigating a simulated phishing campaign within a SOC-style environment using Splunk. The objective was to analyse four security alerts and determine whether each represented genuine malicious activity or a false alarm. By reviewing log data, correlating events, and examining indicators of compromise, I developed a structured approach to alert triage and incident investigation. The challenge also required working efficiently under time pressure, helping me improve my analytical thinking, decision-making, and ability to prioritise multiple investigations simultaneously. Through this project, I gained hands-on experience with alert triage, log analysis, and incident investigation, while developing a better understanding of how SOC analysts assess and respond to potential phishing threats.

SOC Home Lab: Sysmon & Splunk

To gain practical experience with security monitoring tools, I built a home Security Operations Centre (SOC) lab using a Windows 10 virtual machine, Sysmon, Splunk Enterprise, and the Splunk Universal Forwarder. The lab was designed to simulate a real-world monitoring environment where endpoint activity could be collected, forwarded, and analysed. Sysmon was configured using the SwiftOnSecurity configuration to generate detailed endpoint telemetry, which was then forwarded to Splunk for analysis. Throughout the project, I explored process creation events, network activity, and other Windows logs while learning how security analysts monitor and investigate endpoint behaviour. As a result, I gained practical experience with log analysis, SIEM technologies, Sysmon event monitoring, and troubleshooting data ingestion issues, while developing skills relevant to entry-level SOC analyst roles.
