Movies Ratings Dataset Analysis

Completed a project using the IMDb Top 250 Movies dataset, which features 250 iconic films released between 1921 and 2025, including IMDb ratings, number of votes, genres, runtime, certificates, and worldwide gross revenue. I used it to practice SQL and Excel (or Power BI) skills, exploring trends, aggregations, and performance metrics. I analysed how audience ratings, votes, and box office revenue compare across movies, explored trends by genre and year, and identified the top-performing films. The project uncovered interesting patterns and actionable insights about what makes a movie iconic, while also sharpening my data analysis skills.
